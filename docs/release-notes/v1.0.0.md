First release of the OpenEVSE ESP32 Firmware Flasher, a self-contained tool for flashing the OpenEVSE WiFi gateway firmware over USB.

## Supported boards
| Board | Flash | Firmware |
|---|---|---|
| OpenEVSE WiFi V1 (`openevse_wifi_v1`) | 4MB | `openevse_wifi_v1.bin` |
| OpenEVSE WiFi V1 (`openevse_wifi_v1`) | 16MB | `openevse_wifi_v1_16mb.bin` |
| OpenEVSE TFT WiFi V1 (`openevse_tft_wifi_v1`) | 16MB | `openevse_wifi_tft_v1.bin` |

The flash size is read from the ESP32 and the matching firmware, bootloader and partition table are chosen automatically.

## Features
- Firmware from GitHub Releases, the Development Build, GitHub Actions builds, or a local file
- Full install (bootloader + partitions + firmware) or firmware only; optional full erase
- Switches between the 4MB and 16MB layouts while keeping WiFi settings
- Safety checks before writing: image type, size, flash size and board/build match
- Manual boot mode for programmers without auto-reset
- esptool built in; Windows CP210x / CH340 driver install
- Command line mode

## Known issues
- The executables are not code-signed. Chrome, SmartScreen or macOS may warn when you download or open them; see the README for how to keep and run the file.
- The CP210x driver is not bundled (Silicon Labs blocks automated downloads); the app downloads it when you click Install Driver.
- Tested in CI and with simulated hardware; please report any problems flashing real boards.
